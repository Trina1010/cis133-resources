# CIS133 Resources

## HTML Resource

[Learn HTML - web.dev](https://web.dev/learn/html/)

I think web.dev's Learn HTML course is a good resource because it explains HTML concepts in an organized and beginner-friendly way. It includes examples and covers important topics such as document structure, semantic HTML, links, lists, images, and forms.

## CSS Resource

[Learn CSS - web.dev](https://web.dev/learn/css/)

I think web.dev's Learn CSS course is a good resource because it explains CSS topics clearly and provides examples that can help me understand how CSS works. It covers useful topics such as selectors, the box model, Flexbox, Grid, and other modern CSS features.
